# 日語極限默寫教練（龍櫻法 × 回音法）

專為 N4～N3 日語學習者打造的「極限默寫 × 回音朗讀」沉浸式訓練系統。

---

## 🎯 核心特色

1. **AI 教練改寫引擎（龍櫻法）**
   * 自動將零碎的日常日記改寫為 **50～80 字高密度母體短文**（N4～N3 語法骨架）。
   * 提煉 **4～7 個關鍵漢字讀音指引**（排除 N5 簡單詞，聚焦音讀長促濁音、特殊訓讀與動詞幹）。
   * 標註 **白紙審判重點**（助詞與固定搭配、動詞活用變形）。

2. **回音朗讀引擎（回音法 Echo Method）**
   * **逐句停頓（Echo Pause）**：每唸完一句自動安靜 2.5 秒，讓腦海中回響母語發音後再跟讀。
   * **多段語速**：0.8x 抓音調（Accent） ➔ 1.0x 標準 ➔ 1.2x 母語常速。
   * **5～10 遍計數器**：達成目標後解鎖白紙審判。
   * **音檔匯出 & 錄音對照**：支援一鍵下載日語音檔，亦可透過麥克風錄製自己發音自我審查。

3. **白紙審判（零容忍糾錯比對）**
   * 純白紙盲默介面，遮蔽提示進行盲默。
   * **字元級紅筆批改**：自動標記漏掉或錯置的助詞（が/を/に/で/は/へ/から/まで）、動詞變形錯誤。
   * **強制覆寫工作區**：凡錯句，執行「大聲讀 3 遍 + 重新默寫 2 次」。

4. **滾雪球記憶庫（Snowball Archive）**
   * 本地儲存所有練習卡片，自動標記昨日卡片，強制落實「隔天寫新短文前，先在白紙上盲默前一篇」。

5. **A4 練習券一鍵列印**
   * 點擊「列印 A4 默寫單」，自動生成日式 200 字格原稿紙練習單，方便紙筆書寫！

---

## 🚀 快速開始

### 方式一：雙擊【啟動日語極限默寫.bat】（最推薦）
* 雙擊資料夾中的 `啟動日語極限默寫.bat`，系統會自動啟動本地高效神經語音伺服器並自動開啟瀏覽器 `http://localhost:8088`。
* 具備完整功能：AI 改寫、回音播放、白紙審判、以及**一鍵下載高音質 Nanami 日本母語 MP3 音檔**！

### 方式二：直接開啟 index.html
* 亦可直接在檔案總管雙擊 `index.html` 開啟使用（支援 AI 改寫與線上語音跟讀）。

---

## ⚙️ API 與語音設定說明

1. 點擊右上角「**⚙️ 設定**」。
2. 填入您的 **Gemini API Key**（若無 API Key，亦可使用系統內建的 3 篇完整範例，或透過「手動貼入」功能載入）。
3. 語音部分直接調用系統原生日語 TTS（如微軟 Nanami / Keita 或 Google 日本語），開箱即聽！

---

## 🗂️ 檔案結構

* `index.html`：現代化單頁介面（4 階段工作流、回音播放器、白紙審判與 A4 雙頁列印排版）。
* `style.css`：日式深邃美感與白紙質感設計系統、動態波形動畫、紅筆比對高亮、A4 精準 2 頁式列印樣式。
* `app.js`：核心邏輯（Gemini API、逐句回音調度、LCS 字元級 Diff 比對、錄音與音檔匯出）。
* `sample-cards.js`：預設內建 3 篇標準 N4~N3 母體短文範例卡。
* `server.py`：本機輕量語音伺服器（支援微軟神經語音 Nanami / Keita 與大音量增益下載）。
* `package.py`：GitHub Pages 一鍵打包發布與時序壓縮備份腳本。
* `一鍵更新發布包.bat`：Windows 快速一鍵打包批次檔。
* `啟動日語極限默寫.bat`：本機一鍵啟動伺服器與瀏覽器批次檔。

## 📦 一鍵打包發布與 GitHub Pages 同步 SOP

每次修改任何程式碼或文件後，必須依循以下 SOP 進行同步打包：

1. **執行打包腳本**：
   * 在專案根目錄雙擊執行 `一鍵更新發布包.bat`，或在終端機執行：
     ```powershell
     python package.py
     ```
2. **驗證產出**：
   * 確認 `github_deploy/` 資料夾內的 `index.html`、`style.css`、`app.js`、`sample-cards.js` 均為最新狀態（系統已自動更新版本快取戳記 `?v=YYYYMMDD_HHMM` 防止瀏覽器快取舊代碼）。
   * 確認 `releases/` 內已建立最新時序備份壓縮檔（例如 `echo_trainer_YYYYMMDD_HHMM.zip`）。
3. **部署至 GitHub Pages**：
   * 打開瀏覽器進入 GitHub 專案儲存庫頁面。
   * 將 `github_deploy/` 內的所有檔案全選拖曳覆蓋至 GitHub 網頁根目錄發布即可。
